# Kognita 0.6.1

2026-10-31

Patch release for 0.6 "Claims". It closes bypasses found in review of 0.6.0.

## Fixed

- A claim invalidated after its release, for example by superseding its source, no longer covers text on the gateway or communication paths.
- The claim cover check reads only claim events, so it no longer re-verifies the whole evidence chain on every material response.
- A value with `value` and `as_of` but an incomplete fact contract is admitted, and so suppressed, instead of passing through as plain data.
- `verify_claim` pins the producer: provider, model and version must match a recorded `MODEL_CALL`, or verification is denied `C7-PIN`.

## Added

- `release_scope` on a use case (`usecase`, `client` or `interaction`) sets how tightly a claim release is tied to its target. An unknown scope fails closed as `interaction`.

## Changed

- Source lifecycle CLI aliases and house-view supersession regression coverage.
- A developer explainer page at `docs/explainer/kognita.html`.

Included: #134, #136, #137. See the [changelog](../../CHANGELOG.md).
