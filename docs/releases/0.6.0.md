# Kognita 0.6.0 "Claims"

2026-10-30

Material claims are typed, grounded in approved sources, checked for calculation provenance, governed definitions and freshness, and verified by an independent verifier before they reach an RM or client. The gateway and communication paths refuse material output without a released claim, retrieval and tools refuse stale facts, and model and tool events record the in-force standard version.

Also new: memory governance, learning export controls, sensitive-attribute and vulnerable-client safeguards, an evaluation evidence gate with fairness reporting, and retained reasoning traces. All seventeen 0.6 Definition of Done items are met; see [ROADMAP](../ROADMAP.md) and the [changelog](../../CHANGELOG.md).
